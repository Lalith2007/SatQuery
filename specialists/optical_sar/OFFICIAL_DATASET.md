# Official WHU-OPT-SAR Dataset Pipeline & Ingestion Guide

**Dataset Name:** WHU-OPT-SAR Multimodal Remote Sensing Dataset  
**Official Repository:** [https://github.com/AmberHen/WHU-OPT-SAR-dataset](https://github.com/AmberHen/WHU-OPT-SAR-dataset)  
**Authors:** Li et al. (*"MCANet: A joint semantic segmentation framework of optical and SAR images for land use classification"*, IEEE TGRS 2022)  
**Destination Data Directory:** `data/official_whu_opt_sar/`  
**Legacy Synthetic Directory:** `data/optical_sar_whu_benchmark/` (Marked as legacy synthetic testing data only)  

---

## 1. Official Dataset Specifications

- **Original Dimensions:** **5556 × 3704 pixels** per image pair.
- **Image Pairs:** 100 co-registered high-resolution Optical (RGB/NIR) and SAR (Gaofen-3 / Sentinel-1) image pairs.
- **Spatial Resolution:** 5 meters per pixel.
- **Split Strategy:** **SatQuery Custom Image-Level Split** (70 pairs `train`, 15 pairs `val`, 15 pairs `test`).

---

## 2. Official 8-Class Taxonomy vs. SatQuery Query Aggregations

During dataset ingestion and model training, **all 8 official class values are preserved without lossy collapse**:

| Official Label Value | Official Class Name | Internal Model Index | SatQuery Intent Aggregation Target |
| :---: | :--- | :---: | :--- |
| **`0`** | **Background** | `0` | `BACKGROUND` (`Background`) |
| **`10`** | **Farmland** | `1` | `VEGETATION` (`Farmland` + `Forest`) |
| **`20`** | **City** | `2` | `BUILT_UP` (`City` + `Village` + `Road`) |
| **`30`** | **Village** | `3` | `BUILT_UP` (`City` + `Village` + `Road`) |
| **`40`** | **Water** | `4` | `WATER` (`Water`) |
| **`50`** | **Forest** | `5` | `VEGETATION` (`Farmland` + `Forest`) |
| **`60`** | **Road** | `6` | `BUILT_UP` (`City` + `Village` + `Road`) |
| **`70`** | **Others** | `7` | `OTHERS` (`Others` — *NOT collapsed into Background*) |

### Deterministic Query Aggregation Formula:
$$P_{\text{built\_up}} = P(\text{City}) + P(\text{Village}) + P(\text{Road})$$
$$P_{\text{water}} = P(\text{Water})$$
$$P_{\text{vegetation}} = P(\text{Farmland}) + P(\text{Forest})$$
$$P_{\text{others}} = P(\text{Others})$$
$$P_{\text{background}} = P(\text{Background})$$

## 3. Deterministic Border Padding & Tiling (5556 × 3704)

Because raw $5556 \times 3704$ image rasters are not evenly divisible by $256$ ($5556 / 256 = 21.70$, $3704 / 256 = 14.47$), the tiling pipeline applies **deterministic border padding** before cropping:

- **Target Padded Grid:** $5632 \times 3840$ ($22 \times 15$ grid of $256 \times 256$ tiles).
- **Optical & SAR Rasters:** Padded with constant zero intensity (`pad_value = 0`).
- **Ground-Truth Label Masks:** Padded with categorical ignore mask (`ignore_index = 255`).
- **Categorical Nearest-Neighbor Interpolation:** Label masks are cropped or resampled exclusively using `NEAREST` neighbor interpolation (`Image.NEAREST`). Bilinear interpolation is strictly prohibited on categorical masks.
